GCC Bank Management System 🏦

A C++ banking application developed for Gauteng City College.

Features
* User Registration and Login
* Check Account Balance
* Deposit and Withdraw Money
* Send Cash Between Accounts
* Transaction History
* Savings Account Management
* Buy Airtime (Telkom, Vodacom, MTN and Cell C)

Technologies Used
* C++
* Code::Blocks

Purpose: Is To demonstrate basic C++ programming concepts through a simple banking management system.
